# SCT_ML_01
# 🏠 House Price Prediction Web App

A Machine Learning-based web application that predicts house prices based on various input features using **Linear Regression**. The project is deployed as a **Flask web app**, allowing users to interact through a simple and user-friendly interface.

---

## 🚀 Live Demo

👉 (https://sct-ml-01-4hoy.onrender.com/)

---

## 📊 Project Overview

This project takes multiple housing features as input and predicts the estimated house price. It demonstrates a complete **end-to-end Machine Learning pipeline**, from data preprocessing to model deployment.

---

## ✨ Features

- 🧠 Machine Learning model (Linear Regression)
- 🌐 Flask-based web application
- 📱 Simple and interactive UI
- ⚡ Real-time price prediction
- 📊 Multi-feature input system
- 🔁 End-to-end ML workflow (data → model → deployment)

---

## 🧠 Machine Learning Workflow

1. Data Collection
2. Data Preprocessing
3. Feature Selection
4. Model Training (Linear Regression)
5. Model Evaluation
6. Deployment using Flask

---

## 🛠️ Tech Stack

- **Programming Language:** Python
- **Machine Learning:** Scikit-learn, Pandas, NumPy
- **Backend:** Flask
- **Frontend:** HTML, CSS
- **Model:** Linear Regression

---

## 📥 Input Features Used

- Area
- Number of Bedrooms
- Bathrooms
- Stories
- Parking spaces
- Air Conditioning
- Main Road Access
- Guest Room
- Basement
- Hot Water Heating
- Preferred Area
- Furnishing Status
